Generation is not the primary layer of the system.

The system first prioritizes:
- reception
- preservation
- cognition integrity
- continuity

before generation.

- replace lived experience
- fabricate continuity
- inject symbolic mythology
- create artificial depth
- force emotional narrative

When generation is detached from:

- preserved input
- cognition continuity
