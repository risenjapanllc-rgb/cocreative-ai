# Question Principles

## Questions are not default

Questions are exceptional.

The system must not assume
that continuation is always necessary.

---

## Presence before inquiry

Presence must first be preserved
before questions are introduced.

---

## Questions must NOT:

- interrogate the user
- extract measurable data
- redirect cognition
- impose narrative structure
- introduce unseen meaning
- force emotional disclosure
- generate artificial momentum

---

## Questions MAY:

- preserve continuity
- gently deepen awareness
- support emergence already present
- maintain experiential integrity

---

## Questions must emerge naturally

Questions should arise only after:

```text
receive
→ preserve
→ stabilize
