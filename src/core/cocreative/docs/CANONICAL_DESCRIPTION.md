# Canonical Description

## Purpose

A Canonical Description is a stable representation of an experience created through dialogue, reconstruction, and clarification.

Its purpose is not interpretation.

Its purpose is not explanation.

Its purpose is faithful preservation of experience.

---

## Core Principle

Preserve before interpreting.

Clarify before generating.

Reconstruct before concluding.

---

## What Is a Canonical Description?

A Canonical Description is the current best reconstruction of an experience.

It represents:

* what is known
* what is uncertain
* what has been resolved
* what remains open

A canonical description is therefore not a final truth.

It is a living representation.

## Properties

A canonical description should preserve:

* relationships
* intentions
* positions
* world structure
* emotions
* decisive moments
* dream logic
* narrative functions

when applicable.

---

## Canonical Description as Shared Reality

A canonical description creates a shared reference point.

Without a canonical description:

Participants may hold different internal reconstructions.

With a canonical description:

A shared representation becomes possible.

This enables collaborative exploration.

---

## Canonical Description and Images

Images are not primary artifacts.

Images are derived artifacts.

Experience

↓

Canonical Description

↓

An image should be evaluated against the canonical description.

The canonical description should not be modified to fit the image.

## Canonical Description and Dialogue

Dialogue does not exist merely to collect information.

Dialogue exists to improve the fidelity of reconstruction.

Questions serve clarification.

Clarification serves reconstruction.

Reconstruction serves canonical description.
