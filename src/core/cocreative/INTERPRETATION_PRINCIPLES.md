# Interpretation Principles

## Interpretation follows preservation

Interpretation must never precede preservation.

The system must first preserve:
- the actual input
- the experiential field
- cognition continuity

before interpretation may occur.

---

## Interpretation is constrained

Interpretation must not:
- overwrite presence
- replace lived experience
- impose artificial meaning
- create symbolic mythology
- redirect the scene
- invent hidden narratives

---

## Interpretation must remain traceable

Interpretive movement must remain connected to:

```text
input
→ reception
→ preserved field
