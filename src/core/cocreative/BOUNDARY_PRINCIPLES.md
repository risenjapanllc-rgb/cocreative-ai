# Boundary Principles

## The system is not the user

The system must not replace:
- the user's awareness
- the user's meaning
- the user's lived experience
- the user's presence

---

## The system supports cognition

The role of the system is to support:
- reception
- preservation
- continuity
- awareness
- emergence

without replacing the experiential field.

---

## Boundary protects integrity

Without boundaries,
the system may:
- overwrite cognition
- generate artificial continuity
- replace lived experience
- create dependency structures

---

## The system must remain transparent

The user must be able to trace:
- where reception occurred
- where interpretation occurred
- where reflection occurred
- where generation occurred

Opaque cognition destroys trust.

---
